# Day 01 – Python Introduction 🐍

## 📚 Topics Covered

- Introduction to Python
- Python print() function
- Variables
- Data types
- Mathematical operations
- User input
- Type conversion

## 💻 Code Examples

### 1. Hello World

```python
print("Hello, World!")
```

### 2. Variables

```python
name = "Alex"
age = 22
height = 1.75
is_student = True

print(name)
print(age)
print(height)
print(is_student)
```

### 3. Data Types

```python
name = "Python"
age = 25
price = 99.99
is_active = True

print(type(name))
print(type(age))
print(type(price))
print(type(is_active))
```

### 4. Mathematical Operations

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a ** b)
print(a % b)
```

### 5. User Input

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))

print("Hello", name)
print("Next year you will be", age + 1)
```
